# 使用说明

## 一、安装

1. 将 APK 安装到 Android 8.0+ 设备（arm64-v8a / armeabi-v7a 均可）。
   安装时如提示"未知来源应用"，允许即可——本应用为开源社区工具。
2. 打开 **VELA 模拟器**。

## 二、首次准备（约 1–2 分钟）

### 1. 安装 QEMU 运行时
首页顶部有一张 **QEMU 运行时** 卡片，点击后自动执行：
- 从 Termux 官方 apt 仓库（或设置中的清华 TUNA 镜像）获取软件索引；
- 解析 `qemu-system-arm` 的完整依赖闭包（glib、pixman、capstone 等约 20 个包）；
- 逐一下载 → SHA256 校验 → 解包到应用私有目录；
- 修复可执行权限并标记安装完成。

安装状态可在「设置 → QEMU 运行时」中查看或重装。

### 2. 下载设备镜像
进入任一设备模板 → 「自动下载」。清单 `image_manifest.json` 指向本仓库
Release 中的 openvela 官方源码构建镜像，下载完成后自动做 SHA256 校验。

也可以点「导入本地镜像」选择自己构建的 `.elf` 文件（命名需与模板
"仿真参数 → 内核"一致，或先在模板编辑器里改内核文件名）。

## 三、启动模拟

模板详情页点击 **启动模拟** 后进入运行页：

| 视图 | 说明 |
|---|---|
| 控制台 | QEMU 串口 ↔ nsh 命令行。可输入 `help`、`ps`、`free`、`uname -a`、`ls /` 等 |
| 画面 | QEMU VNC 帧缓冲（Raw 编码）。无显示设备的镜像（MPS2 类）为空属正常 |

启动参数由模板自动生成，例如手表类模板：
`qemu-system-arm -M virt -cpu cortex-a7 -smp 1 -m 512M -kernel <镜像> -display none -monitor none -serial tcp:127.0.0.1:<随机端口>,server,nowait -vnc 127.0.0.1:<随机端口>`

## 四、自定义模板

首页底部「新建自定义模板」或模板详情页右上角「编辑」（以原模板为蓝本另存副本）：

- 外观：圆形 / 方形、屏幕尺寸、分辨率（含常见机型预设）、像素密度；
- 仿真：QEMU 机器（virt / mps2-an500 / mps2-an521）、虚拟内存、SMP 核数、附加 QEMU 参数；
- 特性：NFC / eSIM / GPS / 蓝牙 / 心率 / 血氧 / 扬声器 / WLAN（用于展示与归档）。

保存后自动出现在首页"自定义模板"分组。

## 五、常见问题

**Q: 提示 exec 权限错误？**
A: 确认完整安装 QEMU 运行时；本应用 targetSdk=28（Termux 同款方案），
   Android 10+ 系统因此才允许执行应用目录内的 QEMU 二进制。

**Q: 镜像下载缓慢？**
A: GitHub 直连较慢时可用浏览器下载 Release 资产后「导入本地镜像」。

**Q: 控制台出现 `nx_start` 后没有 nsh 提示符？**
A: nsh 需要几秒初始化；若 10 秒后仍无输出，点顶部刷新按钮重启会话。

**Q: 想跑带图形的镜像？**
A: 在模板编辑器的附加参数中添加显示设备（如 `-device virtio-gpu-device`），
   并使用带 framebuffer 驱动的镜像（自行构建时启用相应配置）。
